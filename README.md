# Move Better: Orthopedic Stretch Library

Move Better is a simple, interactive orthopedic stretch library designed to help users explore gentle stretches and mobility exercises for common areas of muscle tightness and discomfort.

The website includes movements for the neck, shoulders, low back, hips, knees, and pain with radiation into an arm or leg. Each stretch includes step-by-step instructions, suggested hold times, repetitions, target areas, and safety guidance.

## Live Website

## Features

- Search stretches by name, muscle, or symptom
- Filter by body region
- Filter by exercise position
- View step-by-step instructions
- See suggested hold times and repetitions
- Review target muscles and body areas
- Read safety warnings for each movement
- Responsive design for desktop and mobile devices
- Self-contained HTML file with no build process required

## How to Use the Website

1. Open the website.
2. Search for a stretch, symptom, muscle, or body region.
3. Use the filters to narrow the results.
4. Select **View instructions** on any stretch card.
5. Follow the movement slowly and remain within a comfortable range.
6. Stop if symptoms become sharper, spread farther into an arm or leg, or cause numbness, tingling, weakness, dizziness, or loss of balance.

## Important Safety Notice

This website is intended for general education only. It does not provide a diagnosis, treatment plan, or substitute for evaluation by a physician, physical therapist, or other qualified healthcare professional.

Users should seek medical care for symptoms such as:

- New or progressive weakness
- Loss of bladder or bowel control
- Numbness in the groin or saddle area
- Severe pain after trauma
- Chest pain or difficulty breathing
- Fever with severe neck or back pain
- A hot, red, or severely swollen joint
- Inability to bear weight or use a limb

People recovering from surgery, injury, or a newly diagnosed condition should consult a qualified healthcare professional before beginning an exercise program.

## How to Publish With GitHub Pages

1. Create a public GitHub repository named:

   `orthopedic-stretch-library`

2. Upload these files to the main folder of the repository:

   - `index.html`
   - `README.md`

3. Commit the files to the `main` branch.

4. Open the repository's **Settings** tab.

5. Select **Pages** from the left sidebar.

6. Under **Build and deployment**, choose:

   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**

7. Select **Save**.

8. GitHub will provide a public website address similar to:

   `https://YOUR-USERNAME.github.io/orthopedic-stretch-library/`

## Updating the Website

To update the project:

1. Open `index.html` in the repository.
2. Select the pencil icon to edit it.
3. Make the changes.
4. Select **Commit changes**.

GitHub Pages will automatically publish the updated version.
